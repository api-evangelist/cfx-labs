CFX Labs provides programmable U.S. banking APIs for global platforms, offering ACH, wire, RTP, cash deposits, virtual accounts, and on‑chain settlement. The fintech‑focused service aggregates deposits across 3,000+ FDIC‑insured banks, tokenizes balances 1:1, and delivers compliance, KYC, and risk controls via a single integration. Backed by multiple venture firms, CFX serves marketplaces, neobanks, card programs, exchanges, and lenders, handling over $1 B in payment volume in 2025 across 67 countries.

**Areas:** Fintech · Banking · Payments · Programmable · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for CFX Labs: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
